# Les épisodes du webtoon : quel fichier pour quel épisode

*17/11/2026. Ce document **fait foi** pour savoir quel fichier utiliser. La liste des épisodes est dans `saison-01-plan.md` (v6, 26 épisodes).*

## La règle
**Le préfixe d'un nom de fichier ne donne pas le numéro de l'épisode.** Plusieurs fichiers anciens s'appellent `ep01-…` alors qu'ils appartiennent à l'ancien épisode 1, « La dernière journée », devenu **l'épisode 3**. Seule la table ci-dessous dit à quoi sert chaque fichier.
