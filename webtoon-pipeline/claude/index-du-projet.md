# Index du projet La Lame-Grise

*Mise à jour : 16/11/2026. Pour chaque fichier : son rôle et son statut. À relire en début de session.*

**Statuts** :
- **fait foi** : la référence sur son sujet ; les autres documents s'y plient ;
- **à jour** : aligné sur les documents qui font foi ;
- **travail** : utile, mais contient des renvois périmés ;
- **v1** : à réécrire ;
- **archive** : remplacé ; à ne plus utiliser comme source ;
- **jeu** : suivi de la campagne Warhammer, hors de l'œuvre.
