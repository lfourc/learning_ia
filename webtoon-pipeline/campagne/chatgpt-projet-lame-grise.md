## 2. Les instructions du projet ChatGPT
Le texte complet à coller est dans `instructions-projet-chatgpt.txt`, envoyé le 15/11/2026. On y trouve :
- le monde : Erdheim, et aucune référence à Warhammer ;
- les sources, par ordre de priorité ;
- les commandes PLANCHE, PAGE, SUITE et CORRIGE ;
- le format PAGE : une image verticale 2:3, avec des cases empilées et aucun texte ;
- les codes visuels de la magie :
  - le mana : des particules dorées ;
  - le Don : une lueur dorée ;
  - le Vif : une lueur ambrée dans les yeux ;
  - l'Ombre : une brume grise argentée ;
  - l'Obscur : un courant noir à reflets violets.

**À corriger dans ce texte** : la numérotation des épisodes. « La dernière journée » est l'épisode 3, et non plus le 10.

## 3. Au quotidien
- **Une conversation par séquence.** Joindre les planches indiquées (3 au maximum), puis coller le prompt de la page, ou écrire « PAGE 5 », puis « SUITE ».
- **Une case ratée** : `CORRIGE case 2 : <consigne>`.
- **Les références validées** : Ottilie (19 ans), Mathilde, Gisela, Ruprecht, Brunhild, Moustache (version avec les gros plans de la tête), Wolfram (30 ans), la planche du manoir en hiver.
- **La page de style** : la page 3 de l'épisode 1 (le cerf, la feuille, le manoir).
- **La génération automatique** : voir `studio/automatisation-generation.md`.
